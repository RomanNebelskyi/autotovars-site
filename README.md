# Autotovars

My first website — a static landing page for an auto parts business (шини, коврики, аксесуари). Built with HTML, CSS (MaterializeCSS), and a bit of jQuery.

This is a personal archive project. It was my first attempt at building a web presence from scratch.

## Structure

```
├── index.html            — Главная страница
├── pages/                — Product category pages
│   ├── tires.html        — Шины
│   ├── carpet.html       — Коврики
│   ├── axess.html        — Аксесуари
│   └── ...               — Brand-specific pages
├── img/                  — Product images and icons
├── css/                  — MaterializeCSS styles
├── js/                   — jQuery and MaterializeJS
└── fonts/                — Material Icons

## Live

<https://RomanNebelskyi.github.io/autotovars-site/>
```

## Run locally

Just open `index.html` in any browser — no build step needed.

## Tech

- HTML5
- CSS3 (MaterializeCSS framework)
- JavaScript (jQuery)
- Google Maps API
